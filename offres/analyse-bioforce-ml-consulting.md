# Analyse du site référence — bioforce.org

**Référence analysée :** https://www.bioforce.org/  
**Client cible :** ML CONSULTING (Niamey, Niger)  
**Prestataire :** Niger Certify  
**Date :** 31 juillet 2026

## Synthèse

Bioforce est un site institutionnel WordPress (v6.9) bilingue FR/EN, orienté formation humanitaire. Il combine vitrine de marque, catalogue de formations filtrable, actualités, missions terrain, espace candidat (Salesforce) et plateforme e-learning (Moodle). Pour ML CONSULTING, l’objectif est un **site similaire en positionnement et expérience utilisateur**, dimensionné à l’échelle d’un cabinet nigérien (pas un clone Salesforce/Moodle).

## Stack technique détectée

| Élément | Détail |
|--------|--------|
| CMS | WordPress 6.9 + Yoast SEO + WP Rocket |
| Serveur | Apache |
| Multilingue | FR / EN |
| Candidatures | Portail Salesforce (`bioforce.my.site.com`) |
| E-learning | Plateforme Moodle dédiée |
| UX | Chatbot, cookies Axeptio, accessibilité UserWay |
| Contenu | CPT formations, missions, actualités, témoignages |

## Architecture fonctionnelle clé

1. **Accueil** — hero plein écran, message de marque, chiffres clés, CTA formations  
2. **Learn** — catalogue filtrable (thématique, objectif, lieu, durée, langue, mode)  
3. **Fiches formation** — sessions, badges (nouveau, complet, bourses), CTA inscription  
4. **Build / Missions** — pages pays (dont Niger)  
5. **Share / Actualités** — blog, webinaires, agenda  
6. **Preuves sociales** — témoignages alumni / ONG  
7. **Conversion** — formulaires, espace candidat, téléchargement brochures  

## Adaptation pour ML CONSULTING

ML Consulting forme et accompagne les métiers de l’action humanitaire à Niamey. Un site type Bioforce allégé doit :

- affirmer la marque et la mission humanitaire dès le premier écran ;
- présenter le catalogue de formations (gestion de projet, MEAL, pré-intégration ONG, etc.) ;
- permettre la pré-inscription / demande de TDR (WhatsApp + formulaire) ;
- publier actualités et sessions ;
- rester administrable en autonomie (WordPress).

Hors périmètre recommandé en phase 1 : portail Salesforce, LMS Moodle complet, chatbot IA, bilingue EN (option).
