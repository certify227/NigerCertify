# Analyse technique — Site de référence

**Référence analysée :** https://iafr-ahd.com/  
**Contexte :** L’URL n’ayant pas été jointe au brief, le site IAFR-AHD a été retenu comme benchmark le plus proche du positionnement de **ML CONSULTING** (cabinet de formation / conseil en action humanitaire & développement).  
**Prestataire :** Niger Certify  
**Client cible :** ML CONSULTING (Niamey, Niger)  
**Date d’analyse :** 31 juillet 2026  

---

## 1. Positionnement du site de référence

IAFR-AHD est un site vitrine + plateforme de conversion pour un cabinet africain spécialisé dans :

- formation professionnelle / spécialisations certifiantes ;
- appui-conseil organisationnel aux ONG ;
- recherche-action et évaluation ;
- recrutement et inscription en ligne.

C’est exactement le type de présence digitale manquante aujourd’hui à ML CONSULTING, qui communique surtout via LinkedIn, Facebook et annonces (NigerEmploi, JobRapide).

---

## 2. Architecture des pages

| Page | Rôle | Complexité |
|------|------|------------|
| Accueil | Hero, à propos, domaines, témoignages, actualités, partenaires, CTA | Élevée |
| Présentation | Mission, vision, équipe | Moyenne |
| Domaines | Catalogue d’expertises / formations | Moyenne |
| Actualités | Blog / événements dynamiques | Moyenne |
| Recrutement | Offres + candidature (upload CV) | Élevée |
| Cours | Espace apprenant (login + vidéos) | Très élevée |
| Contact | Coordonnées + formulaire + carte | Moyenne |
| Inscription en ligne | Formulaire multi-champs + validation | Élevée |
| Politique de confidentialité | Conformité | Faible |

**Navigation :** menu desktop + burger mobile, dropdown Actualités, CTA « INSCRIPTION EN LIGNE », sélecteur FR/EN.

---

## 3. Fonctionnalités identifiées

1. **Design responsive** (mobile / tablette / desktop)  
2. **Hero full-bleed** avec image WebP, animations (fade-in, particules)  
3. **Compteurs animés** (stats staff / stagiaires / consultants)  
4. **Témoignages** bénéficiaires  
5. **Formulaire d’inscription** (formation, motivation, consentement)  
6. **Formulaire de contact**  
7. **Espace cours** authentifié (email / mot de passe, filtres cohorte / année)  
8. **Recrutement** avec upload CV (PDF/DOC, max 5 Mo)  
9. **Actualités dynamiques** (chargement asynchrone)  
10. **Bilingue FR / EN**  
11. **SEO** : meta description, Open Graph, Twitter Card, Schema.org Organization, canonical  
12. **Tracking** Meta Pixel  
13. **Pied de page** structuré (liens, contact, horaires)

---

## 4. Stack technique observée

- HTML / CSS / JS custom (pas de CMS WordPress visible en façade)
- Assets organisés (`assets/css`, `assets/img`)
- Images optimisées WebP
- Scripts d’animation côté client
- Backend probable pour inscriptions, actualités, cours et recrutement

---

## 5. Écart ML CONSULTING vs référence

| Besoin ML CONSULTING | État actuel | Sur un site équivalent |
|----------------------|-------------|------------------------|
| Crédibilité institutionnelle | Faible (pas de site dédié) | Forte (vitrine + preuves) |
| Catalogue de formations | PDF / annonces | Pages structurées + filtres |
| Inscriptions | WhatsApp / email | Formulaire en ligne + confirmation |
| Témoignages / impact | Posts LinkedIn | Section dédiée + actualités |
| Recrutement / partenariats ONG | Informal | Module dédié |
| Formation en ligne | Non | Espace cours (option Premium) |

---

## 6. Périmètre recommandé pour ML CONSULTING

### Pack Professionnel (recommandé)
Site équivalent à ~80 % d’IAFR-AHD **sans** l’espace e-learning vidéo :

- 7–8 pages + CMS léger  
- Inscriptions & contact  
- Actualités  
- Recrutement basique  
- SEO + responsive + hébergement 12 mois  

### Pack Premium (équivalent complet)
Tout le Professionnel **+** espace cours (comptes apprenants, catalogue vidéo, cohortes).

Les montants détaillés figurent dans la **facture proforma** jointe.
